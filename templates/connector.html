How an agent uses it

  1. search_businesses — find the business by name.
  2. get_business — see its actions, parameters, and which ones need human approval.
  3. call_action — run the action. Booking and order actions are flagged, so the agent asks you first.

Every business also keeps its own portable API (/a/<id>/mcp) that works with any agent, on any platform — the connector is distribution, not lock-in.
