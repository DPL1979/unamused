# Unamused — free, open-source website audit for the agent era

**Is Muse unamused by your business?** Paste a website, get a 0–100 score on whether
agents like Muse can read the site, recommend the business, and complete a booking.
Don't be unamused.

- **Free forever.** No signup, no paywall on the audit or the fix kit.
- **Open methodology.** The scoring is right here — inspect it, argue with it, improve it.
- **Honest by design.** We weight what lets an agent *complete a task* (booking surface
  + structured data), not snake oil: `llms.txt` is checked but scored 5/100, because
  2026 server-log studies show ~97% of those files get zero requests and no major AI
  provider confirms consuming it.

## What it checks (100 pts)

| Check | Pts | What it measures |
|---|---|---|
| Action surface | 25 | Can an agent book, order, or contact you — or just read about you? |
| Structured data | 20 | schema.org JSON-LD: name, phone, address, hours, geo |
| Machine-readable contact | 15 | tap-to-call links, address/hours in plain text |
| Semantic HTML | 10 | title, headings, landmarks — how agents parse a page |
| Discoverability | 10 | sitemap.xml + robots.txt posture toward AI crawlers |
| Hygiene | 10 | HTTPS, mobile viewport, response speed |
| llms.txt | 5 | checked as cheap hygiene, not a lever (see above) |
| Social previews | 5 | Open Graph tags |

Grades: **85+ Amused · 65+ Almost amused · 40+ Unamused · under 40 Deeply unamused**

## The free Fix Kit

Every audit can generate a personalized fix kit: curated `llms.txt`, pre-filled
JSON-LD schema markup, robots.txt, Open Graph tags, and step-by-step install guides
for WordPress, Wix, Squarespace, Shopify, and custom sites. Download it from any
report page — free.

## Run it

```bash
pip install -r requirements.txt
python3 app.py          # http://127.0.0.1:8000
```

CLI audit: `python3 audit.py https://example.com`
CLI fix kit: `python3 fixkit.py https://example.com --out fixkits/`

Production: `gunicorn -w 1 --threads 4 -b 127.0.0.1:8000 app:app` behind nginx — see
[DEPLOY.md](DEPLOY.md). Set the `GITHUB_URL` env var to wire
up the repo link.

## Business model

Free and open source, no paid tiers. The audit, the Fix Kit, and the Amused
badge (earned at 85+ by re-audit) all cost nothing. Sustainability comes from
distribution: every generated file carries a `Generated by Unamused` credit
line, and every badge links back. If paid services ever appear, they'll be
announced — nothing is sold today.
